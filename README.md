# dot. ✳

A minimalist, surprisingly deep idle clicker built for phones and desktops.

**Play:** https://shukritobi.github.io/idle-clicker-game/

## Features

- Tap the energy orb, build a 75× combo streak, and land critical hits.
- Buy **20 escalating generators** with seven production milestones: 10, 25, 50, 100, 200, 400 and 800 units.
- Research **6 upgrade trees**: tapping, luck, combos, discounts, production and offline collection.
- Trigger **Overdrive** for 3× power, catch surprise meteors, and claim daily rewards.
- Earn **24 achievements**. Ascend after 1M run earnings to gain permanent stars. Each star adds 14% to production and taps.
- Automatic local saves, capped offline earnings, JSON save export/import, and reset.
- Custom procedural Web Audio click, purchase, critical, achievement, and prestige effects, with optional ambient melody.
- Responsive interface, reduced-motion support, installable PWA and offline caching.

## Run locally

No build tools or dependencies:

```sh
python3 -m http.server 5173
```

Visit http://localhost:5173

## Meme reactions + sound pack

- Manual-tap streaks of **10 / 50 / 100 / 250 / 500 / 1,000 / 2,500 / 5,000 / 10,000** trigger a meme-styled audio celebration, original animated pixel GIF and a one-time energy bonus for each crossed milestone in the active streak. Higher milestones reuse the largest GIF.
- Distinct clips and synth accents trigger for purchases, upgrades, achievements, daily rewards, meteors, overdrive, prestige and lucky hits. Fast ordinary taps keep short low-volume synth clicks to avoid audio clutter.
- GIFs are generated by `node scripts/create-reactions.cjs` under `assets/reactions/`. They're original pixel art: dancing cat, meme chef, expanding brain, cinema and crowned champion.
- CC0 OGG effects are prepared by `node scripts/prepare-sounds.cjs` under `assets/audio/`. Only verified Kenney game sounds are bundled. No copyrighted voice clips, songs or TV/movie meme recordings are redistributed.
- Source repositories: [Kenney UI sounds](https://github.com/GeorgeQLe/assets-sfx-ui), [Kenney impact and RPG sounds](https://github.com/GeorgeQLe/assets-sfx-combat); audio licensed **CC0-1.0** by Kenney Vleugels, [kenney.nl](https://kenney.nl).
- The audio engine always includes original synth fallbacks if an audio file is not available. Each new audio file plays only after a user gesture (iOS policy). The music, regular SFX, visual effects and meme popups have separate options.

To prepare a complete offline-playable build locally, first run:

```sh
node scripts/create-reactions.cjs
node scripts/prepare-sounds.cjs
python3 -m http.server 5173
```

GitHub Actions prepares these files automatically before publishing.

**Autosave:** every three seconds while playing, after purchases/upgrades/rewards, on page hide and before unloading. An on-screen save indicator updates after each successful localStorage write. JSON import/export remains available in More.

## GitHub Pages deployment

The workflow at `.github/workflows/pages.yml` publishes on every push to main.

**First-time setup if Pages is disabled:** Open **Settings → Pages → Build and deployment → Source: GitHub Actions**. Then rerun the workflow. The default GitHub Actions token cannot enable a disabled Pages site automatically.

## Manual test checklist

1. Tap, buy generators, test ×1, ×10, MAX and all lab upgrades.
2. Verify production milestones, saved progress and offline earnings.
3. Check audio on iPhone after the first tap and the separate ambient toggle.
4. Export, reset and import a save.
5. Earn 1M and prestige. Verify the permanent power bonus.
6. Install to home screen and test airplane mode after the first successful visit.

The game runs entirely in the browser. Save data stays in device localStorage.
